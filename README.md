# ARIA (JNectarTech)

AI research verification: lock the success rules, record every run, get an honest verdict.

Built with Next.js, Supabase and Vercel.

Setup: run supabase/schema.sql then supabase/migration2.sql in the Supabase SQL Editor, set NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY in Vercel, and add your Vercel address to Supabase Auth redirect URLs.
